게임 화면을 더 부드럽게

화면을 캡처해서 프레임 사이에 중간 프레임을 만들어 넣고, 작은 창으로 띄운 게임을 화면 크기로 선명하게 키워요. 게임 파일이나 메모리는 건드리지 않아요.

프레임 생성

2·3·4배 또는 모니터 주사율에 맞춘 자동 모드. 실제 배수와 추가 지연을 화면에 숫자로 보여 줘요.

업스케일 + 선명화

낮은 해상도 창 모드 게임을 화면 크기로 키우고 선명도를 조절해요.

자원 분배

게임 말고 다른 프로그램의 CPU 우선순위를 낮춰요. 끄면 원래대로 돌아가요.

자동 업데이트

새 버전을 알아서 받아 두고, 앱을 끌 때 적용해요. 설정과 기록은 그대로예요.

업데이트 예정

SystemBoost 0.9.0

💳 카드 자동 결제

프리미엄과 울트라(월간·연간)를 카드로 결제하고 기간마다 자동으로 이어서 쓸 수 있게 돼요.

  • 언제든 해지할 수 있고, 해지해도 이미 낸 기간까지는 써요.
  • 계좌이체 같은 1회 결제도 그대로 남아요.
  • 카드 정보는 결제 업체(Lemon Squeezy)가 처리하고, SystemBoost는 받지도 저장하지도 않아요.

🟥 AMD 라데온 지원

라데온 그래픽카드에서 쓸 수 있는 기능이 늘어나요. AMD 공식 ADLX SDK를 써요.

  • 게임별 드라이버 프로필 (지원하는 GPU에서 Anti-Lag 등)
  • 전력 제한 / 오버클럭 (울트라) · 기본 꺼짐, 온도 초과나 오류 시 자동 복구
  • 프레임 생성과 업스케일은 지금도 라데온에서 쓸 수 있어요.

아직 개발 중인 기능이에요. 출시일과 실제로 시험한 범위는 출시 때 이 페이지와 공식 디스코드 #announcements에 알려 드려요. 카드 자동 결제에 맞춰 사용권 계약이 바뀌어요. 바뀐 계약은 시행 30일 전에 미리 알리고, 앱에서 다시 동의를 받아요. 그 전까지는 지금 계약과 요금제가 그대로 적용돼요.

  • 자동 결제는 없어요. 월간·연간 키는 기간이 끝나면 무료 플랜으로 돌아가요. 계속 쓰려면 다시 결제하면 돼요.
  • 결제는 앱의 프리미엄 화면에서 해요. 결제가 확인되면 라이선스 키가 앱에 바로 등록돼요. 결제가 열리기 전에는 버튼이 '결제 준비 중'으로 보여요.

  • 추천 코드나 초대 코드가 있으면 프리미엄 화면과 계정 메뉴에서 입력할 수 있어요.
  • 키는 받은 날부터 7일 안에 청약을 철회할 수 있어요. 키를 등록해 유료 기능을 쓰기 시작하면 철회가 제한될 수 있어요. 자세한 조건은 사용권 계약 제9조에 있어요.

설치

Windows
  1. 설치판을 받아 실행하면 바로 설치되고 켜져요. 관리자 권한은 필요 없어요.
  2. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누르세요. 아직 코드 서명 전이라 처음 한 번 떠요.
  3. 포터블은 압축을 풀고 SystemBoost.exe를 실행하면 돼요.
macOS
  1. 칩에 맞는 .pkg를 받아 설치하세요. Apple 메뉴 → 이 Mac에 관하여에서 칩을 확인할 수 있어요.
  2. 처음 켤 때 '화면 기록' 권한을 허용해 주세요. 게임 화면을 캡처하는 데 필요해요.
알아 두세요

프레임 생성은 다음 프레임을 기다려야 해서 입력 지연이 조금 늘어요(늘어난 값은 프로그램에 표시돼요). 빠른 반응이 중요한 경쟁 게임에는 권장하지 않아요.

게임은 테두리 없는 창 또는 창 모드로 실행해 주세요.
