## B. 새 사용자 계정에서 처음부터 [사용자 필요]

1. 새 Windows 사용자 계정을 만들고 로그인합니다(설정 → 계정 → 다른 사용자).
2. `SystemBoost-Windows-Setup.exe`를 설치합니다.
3. 사용권 계약 화면: **'사용 통계 보내기'가 체크되어 있지 않은지** 확인 → 동의하고 시작.
4. ★ 플랜: '3일 체험' 안내가 체험 버튼과 결제 카드 **위에** 있는지 확인 → '3일 체험 시작'.
   - 울트라로 바뀌고, 키 설명이 "3일 체험 키 · 끝나면 무료 플랜으로 돌아가요"인지 확인.
   - 다시 눌러 볼 수 없게 체험 칸이 사라지는지 확인.
5. 게임 부스트를 몇 개 켭니다 → '백업 · 되돌리기' → **모두 되돌리기** → 바뀐 설정이 돌아왔는지 확인.
6. 앱을 끄고 '앱 및 기능'에서 SystemBoost를 제거합니다.
7. 같은 PC에서 다시 설치하고 체험을 누르면 "이 PC는 이미 체험을 받았어요"가 나오는지 확인합니다(PC마다 한 번).
8. 시험이 끝나면 시험용 사용자 계정을 지웁니다.

## C. 업데이트 0.8.13 → 0.8.14 [사용자 필요]

1. 시험 계정에 0.8.13을 설치합니다(GitHub 릴리스 v0.8.13).
2. 0.8.14 릴리스가 올라간 뒤 설정 → 업데이트 → 지금 확인 → 다시 시작.
3. 사용권 계약을 **다시 묻는지**, 통계 체크가 꺼져 있는지 확인합니다(예전에 켜 둔 경우도).
4. 키, 설정, 기록이 그대로인지 확인합니다.
5. 새 저장소(SystemBoost-releases)를 만든 뒤라면: 0.8.14가 두 저장소에 모두 있는지, 0.8.14 앱의 '지금 확인'이 "최신"이라고 하는지 확인합니다.

## D. 인터넷이 없을 때, 서버가 멈췄을 때 [사용자 필요]

1. 네트워크를 끄고 앱을 켭니다 → 무료 기능이 그대로 되고, 체험 버튼은 "서버에 연결하지 못했어요"를 보여 주는지.
2. 이미 등록한 키가 계속 열려 있는지(오프라인 확인).
3. 서버가 멈춘 경우는 시험용 서버(아래 E)를 끈 상태로 같은 확인을 합니다. **운영 서버를 끄지 마세요.**

## E. 결제 흐름 (SALES_MODE=test, 시험용 서버) [사용자 필요]

운영 서버와 운영 KV에 시험 주문을 만들지 않습니다. Cloudflare에 **시험용 Worker와 시험용 KV**를 따로 만들어 쓰고,
앱은 시험용 주소를 가리키는 빌드로 시험합니다(Claude가 만들어 드릴 수 있습니다).

1. 계좌이체: 앱에서 주문 → 주문 코드 받기 → (실제 입금 없이) '고객센터에 입금 알리기' → 고객센터 '입금 확인' 문의가 채워져 열리는지 → 보내기
   → 관리자 화면에서 남은 시간(20시간 노랑, 24시간 빨강)과 승인/거절 → 승인하면 앱에 키가 뜨고 문의에 자동 답이 붙는지.
   각 단계 화면을 캡처합니다.
2. 판매자 Discord 알림: 시험 서버에 ADMIN_ALERT_WEBHOOK(시험 채널)을 넣고, 알림에 주문 코드·플랜·금액·남은 시간만 있고 메일·이름이 없는지 확인.
3. 카드: Lemon Squeezy 시험 모드 결제 → 키 자동 발급 → 구독 관리 링크. 캡처.
4. 판매자 정보 빈칸 막기: SALES_MODE=live인 시험 서버에서 판매자 정보 하나를 비우면 결제 버튼이 "결제 준비 중"이고 주문이 막히는지.
