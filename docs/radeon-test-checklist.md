# 라데온 PC 시험 체크리스트 (베타 테스터용)

SystemBoost의 AMD 라데온 기능은 **아직 실제 라데온 PC에서 시험하지 않았어요.** 이 목록은 라데온 그래픽카드가 있는 분이
직접 해 보고 결과를 알려 주시는 순서예요. 30~40분쯤 걸려요. 하다가 이상하면 바로 멈추고, 아래 '문제가 생기면'을 따라 주세요.

## 시작하기 전에

1. **라데온 기능이 들어 있는 시험판인지 확인해요.** SystemBoost를 켜고 왼쪽 'GPU · 오버클럭'을 눌러요.
   - "AMD 드라이버 기능은 아직 준비 중이에요"가 보이면 이 판에는 라데온 기능이 없어요. 시험판을 받은 뒤에 해 주세요.
   - "AMD 드라이버가 오래돼서 쓸 수 없어요"가 보이면 AMD Software(Adrenalin)에서 드라이버를 업데이트해요.
2. **데스크톱 PC**에서 해 주세요. 노트북이나 내장 그래픽(APU)에서는 1, 2, 5번만 하면 돼요(전력·클럭 조정은 데스크톱 전용이에요).
3. 3번과 4번(전력 제한·오버클럭)은 **울트라 플랜**에서만 열려요. 시험용 키는 판매자에게 받아 주세요.
4. **지금 값을 적어 두세요.** AMD Software → 성능 → 튜닝에서 전력 제한, GPU 최대 클럭, VRAM 최대 클럭을, AMD Software →
   게임 → 그래픽(전체 설정)에서 Radeon Anti-Lag, Radeon Chill, Radeon Boost, AMD Fluid Motion Frames(AFMF)가 켜져 있는지 꺼져 있는지
   적거나 화면을 찍어 두세요. 나중에 원래대로 돌아왔는지 비교할 때 써요.
5. 시험에는 **안티치트가 없는 게임**(혼자 하는 게임, 게임 안 벤치마크가 있는 게임)을 써 주세요. SystemBoost는 게임에 코드를 넣거나
   게임 메모리를 읽지 않지만, 안티치트 프로그램과 함께 써도 괜찮은지는 아직 확인하지 않았어요.
6. 그래픽카드가 뜨거워질 수 있어요. 케이스 팬이 정상인지 보고, 게임 중 온도가 90 °C를 넘으면 바로 게임을 끄세요.

## 1. 그래픽카드 이름·온도·클럭이 제대로 보이나요?

1. 왼쪽 '대시보드'의 '그래픽카드' 칸에 카드 이름(예: "AMD Radeon RX 7800 XT")이 나오는지 봐요.
2. 왼쪽 'GPU · 오버클럭'의 그래픽카드 칸에 온도, 핫스폿 온도, GPU 클럭, VRAM 클럭, 전력, 사용률, VRAM 사용량이 나오는지 봐요.
3. AMD Software → 성능 → 지표에 나오는 값과 비교해요. 몇 초 차이로 조금 다른 건 괜찮아요. 크게 다르거나 비어 있는 칸을 적어 주세요.
4. 게임을 켠 상태에서도 한 번 더 봐요(온도와 사용률이 올라가야 해요).

## 2. 게임을 켜면 Anti-Lag가 켜지고, 끄면 원래대로 돌아오나요?

1. 'GPU · 오버클럭'에서 **'드라이버 게임 프로필'** 스위치를 켜요. 관리자 권한 창이 뜨면 '예'를 눌러요.
2. '게임 부스트'의 게임 목록에 시험할 게임을 추가해요.
3. 게임을 켜요. 30초쯤 뒤에 AMD Software → 게임 → 그래픽(전체 설정)을 열어 **Anti-Lag 켜짐, Radeon Chill 꺼짐**인지 봐요.
   (Radeon Boost는 SystemBoost가 바꾸지 않고 상태만 보여 줘요.)
4. 게임을 꺼요. 30초쯤 뒤에 같은 화면에서 **시작 전에 적어 둔 값**으로 돌아왔는지 봐요.
5. SystemBoost의 '최근 동작'에 켠 것·되돌린 것이 적혔는지 봐요.
6. 게임 중에 AMD Software에서 Anti-Lag나 Chill을 직접 바꾼 경우에는, 게임을 끌 때 SystemBoost가 그 값을 그대로 두고
   "게임 중에 다른 값으로 바뀌어 있어서 그대로 뒀어요"라고 알려야 해요. 해 보셨다면 결과를 적어 주세요.

## 3. 전력 제한·오버클럭 적용 → 벤치마크 전·후 FPS → 되돌리기 (울트라)

1. **적용 전 측정:** 게임 안 벤치마크(또는 같은 장면)를 3번 돌려 평균 FPS와 1% Low FPS를 적어요. SystemBoost의
   '벤치마크 · 기록'을 써도 돼요.
2. 'GPU · 오버클럭'의 '오버클럭 / 전력 제한 값'에서 작은 값부터 골라요. 예: 전력 제한 +5%, GPU 최대 클럭 +100 MHz, VRAM 최대 클럭 +50 MHz.
   한 번에 이보다 많이 올릴 수는 없어요.
3. 위험 안내를 읽고 체크한 뒤 **'오버클럭 / 전력 제한'** 스위치를 켜요.
4. 화면과 게임이 정상이면 25초 안에 **'유지'**를 눌러요. 누르지 않으면 원래 값으로 돌아가야 해요. **한 번은 일부러 누르지 말고**
   돌아오는지도 봐 주세요.
5. **적용 후 측정:** 1번과 같은 방법으로 3번 돌려 적어요.
6. 스위치를 꺼요(또는 왼쪽 '백업 · 되돌리기'의 '전체 되돌리기'). AMD Software → 성능 → 튜닝 값이 시작 전에 적어 둔 값으로 돌아왔는지 봐요.
7. '공장 초기값으로 복구' 버튼도 한 번 눌러 보고, AMD Software에서 값이 기본값이 됐는지 봐요(이 버튼은 모든 플랜에서 돼요).
8. 자동 튜닝(자동 언더볼트, 자동 GPU 오버클럭, 자동 VRAM 오버클럭)을 시험하실 때는 **'공장 초기값으로 복구'를 먼저 누른 뒤**
   해 주세요. 1분쯤 걸리고, 끝난 뒤 '유지'를 눌러야 남아요. 공장 초기값이 아닌 상태에서 자동 튜닝을 쓰면 되돌릴 때 전압 값은
   그대로 남을 수 있어요.

## 4. 제한 온도를 낮게 잡으면 자동으로 돌아오나요? (울트라)

1. 'GPU · 오버클럭'에서 **'제한 온도'**를 가장 낮은 60 °C로 바꿔요.
2. 3번처럼 작은 값으로 '오버클럭 / 전력 제한'을 켜고 '유지'를 눌러요.
3. 게임을 켜서 그래픽카드 온도를 60 °C 넘게 올려요.
4. 60 °C 이상이 3초쯤 이어지면 **공장 초기값으로 돌아가고 알림이 떠야** 해요. 알림 문구와 그때의 온도를 적어 주세요.
5. AMD Software → 성능 → 튜닝에서 값이 기본값인지 봐요.
6. 끝나면 '제한 온도'를 다시 83 °C(기본)로 바꿔요.

## 5. AFMF를 켠 상태에서 안내가 뜨나요?

1. AMD Software → 게임 → 그래픽에서 **AMD Fluid Motion Frames**를 켜요(지원하는 카드와 드라이버에서만 보여요).
2. 게임을 켜고 SystemBoost의 '프레임 생성'을 시작해요.
3. 프레임 생성 화면에 "AMD Fluid Motion Frames가 켜져 있어요. SystemBoost 프레임 생성과 같이 쓰면 화면이 흔들릴 수 있어요.
   하나만 켜 주세요."라는 안내와 **'AMD Software 열기'** 버튼이 나오는지 봐요. 버튼을 누르면 AMD Software가 열려야 해요.
4. SystemBoost가 AFMF를 몰래 끄지 않았는지(AMD Software에서 여전히 켜져 있는지) 봐요.
5. 끝나면 AFMF를 원래대로 돌려 두세요.

## 6. 작업 관리자로 강제 종료한 뒤 다시 켜면 원래 값으로 돌아오나요?

1. 3번처럼 '오버클럭 / 전력 제한'을 켜고 '유지'를 눌러요. 2번의 '드라이버 게임 프로필'도 켠 상태로 게임을 켜요.
2. 작업 관리자(Ctrl + Shift + Esc)에서 **SystemBoost**를 골라 '작업 끝내기'를 눌러요.
3. AMD Software에서 지금 값(튜닝 값, Anti-Lag·Chill)을 적어요.
4. 게임을 끄고 SystemBoost를 다시 켜요.
5. 시작할 때 "SystemBoost가 갑자기 꺼져서 AMD 그래픽카드 설정(전력·클럭)을 원래대로 돌렸어요" 같은 알림이 뜨고,
   튜닝이 **다시 적용되지 않는지** 봐요.
6. AMD Software의 값이 시작 전에 적어 둔 값과 같은지 봐요.
7. 할 수 있다면 PC를 재부팅한 뒤에도 같은 값인지 봐 주세요.

## 문제가 생기면

- 화면이 꺼지거나 게임이 멈추면 PC를 다시 켜요. SystemBoost를 켜면 저장해 둔 원래 값으로 돌려요.
- 그래도 값이 이상하면 AMD Software → 성능 → 튜닝에서 **'초기화'(공장 초기값)**를 눌러요.
- Anti-Lag·Chill이 이상하면 AMD Software → 게임 → 그래픽에서 원래 값으로 직접 바꿔요.
- 무슨 일이 있었는지 아래 양식에 적어 주세요. 화면 사진이 있으면 더 좋아요.
