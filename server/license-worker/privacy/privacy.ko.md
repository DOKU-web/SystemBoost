# SystemBoost 개인정보 처리방침

SystemBoost 판매자(이하 "판매자")는 SystemBoost 앱, 라이선스 서버, 고객센터(앱의 '고객센터'와 웹 /help)를 운영하면서 아래와 같이 개인정보를 처리해요. 판매자 정보는 앱의 ★ 플랜 화면, 고객센터의 '판매자 정보', 웹 /help에서 볼 수 있어요.

시행일: {{EFFECTIVE_DATE}}

## 한눈에 보기

- 앱은 회원 가입 없이 쓸 수 있어요. 회원 가입에는 메일 주소나 이름을 받지 않아요.
- 카드 번호는 Lemon Squeezy 결제창에서만 입력해요. 카드 번호는 SystemBoost 앱과 판매자 서버에 오지 않고, 판매자 서버는 카드에 관한 정보를 저장하지 않아요.
- 판매자 서버는 Cloudflare(미국 회사)에서 돌아가고, 회원 정보는 Supabase에 있어요. 그래서 개인정보가 국외에서 처리되고 보관돼요(제4조).
- 키 기록과 메일 주소 색인처럼 보관 기간을 정하지 않은 기록이 있어요. 무엇이 얼마나 남는지는 제2조에 하나씩 적었어요.
- 개인정보를 광고나 마케팅에 쓰지 않고, 다른 사람에게 팔거나 제공하지 않아요.

## 제1조 처리하는 개인정보와 목적

| 언제 | 처리하는 항목 | 목적 |
|---|---|---|
| 키를 등록한 앱을 켤 때와, 켜 둔 동안 20시간에 한 번까지 (인터넷 연결 시) | 라이선스 키 식별 번호(키에서 계산한 16자리) | 키가 막혔는지 확인. 판매자 서버는 이 요청을 저장소에 남기지 않아요 |
| 구독 키가 끝나기 7일 전 | 구독 번호, 지금 쓰는 키 전체(그 구독의 키인지 확인에만 쓰고 저장하지 않아요) | 다음 기간의 키 받기. 판매자 서버는 이 요청을 저장소에 남기지 않아요 |
| 계좌이체 · 직접 결제 | 주문 코드, 플랜, 결제 방식, 주문 상태와 시각, 사용자가 적은 입금자명과 결제 메모, 할인 티켓을 쓴 경우 그 할인율. 판매자가 승인하면 키 식별 번호, 판매자가 적은 메일 주소(선택), 묶음 키의 개수. 판매자가 거절하면 거절 사유, 환불하면 환불 시각 | 결제 확인과 키 발급. 판매자는 결제 서비스나 계좌의 결제 내역(입금자명, 금액, 메모)을 주문과 맞춰 봐요 |
| 카드 결제 | Lemon Squeezy가 판매자 서버로 보내는 결제 알림의 결제 메일 주소, 구독 번호, 주문 번호, 결제 번호(자동 결제 한 번마다의 번호), 산 상품(플랜), 다음 결제일, 구독 상태, 시험 결제인지, 주문 코드. 판매자 서버는 이 가운데 메일 주소, 구독 번호, 주문 번호, 결제 번호, 플랜, 만료일(다음 결제일로 계산), 시험 결제인지, 주문 코드만 저장하고, 결제 알림에 들어 있는 다른 정보(이름 등)는 저장하지 않아요. 메일 주소는 주문, 키 기록, 메일 주소로 키를 찾는 색인, 판매자 작업 기록에 남아요 | 키 자동 발급과 갱신, 환불한 키 막기, 키를 잃어버렸을 때 찾아 주기 |
| 키를 발급할 때 (모든 키) | 키 전체, 키 식별 번호, 플랜, 발급일과 만료일, 받은 경로(직접 결제, 카드, 추천 코드와 초대, 판매자 발급), 메일 주소(카드 결제 메일 또는 판매자가 적은 메일), 메모(주문 코드, 판매자가 적은 메모, 판매자가 메모를 비우고 승인한 직접 결제는 입금자명과 결제 메모, 추천 코드, 초대 보상이면 회원 아이디), 구독 번호, 시험 결제의 키인지, 막았는지와 그 사유. 키 안에도 플랜, 메일 주소, 발급일, 구독 번호, 만료일이 들어 있어서, 키를 다른 사람에게 보여 주면 메일 주소도 함께 보여요 | 키 발급, 확인, 막기, 다시 보내기, 환불 |
| 추천 코드나 초대 코드를 쓸 때 | 코드, 앱이 만든 무작위 기기 번호 | 한 기기가 코드를 한 번만 쓰게 하기. 회원 가입 때도 기기 번호를 보내지만, 초대 코드를 쓴 경우에만 저장해요 |
| 판매자가 추천 코드를 만들 때 | 코드, 판매자가 적은 이름표(예: 코드를 준 사람), 플랜과 기간, 사용 횟수 | 추천 코드 관리와 코드를 퍼뜨린 사람의 보상 |
| 회원 가입과 회원 기능 (선택) | 아이디, 비밀번호와 복구 코드(해시값으로만 저장), 가입과 마지막 로그인 시각, 동의한 안내문의 판과 동의 시각, 초대 코드, 초대한 회원, 초대 수와 보상 일수, 할인 티켓(할인율, 만료일, 쓴 주문 코드, 쓴 시각), 로그인 실패 횟수와 잠금 시각, 차단 여부, 로그인 세션(해시값과 만료 시각) | 회원 관리, 초대 보상, 할인 티켓 |
| 고객센터 문의와 환불 요청 | 필수: 문의 종류, 제목, 내용, 판매자의 답, 글마다의 시각, 문의 상태, 동의한 시각, 언어, 확인 코드(해시값), 앱에서 회원으로 로그인 중이면 회원 아이디, 환불 요청이면 환불 사유. 적거나 고른 경우만: 연락처, 주문 코드, 키 식별 번호(키 전체를 보냈다면 서명을 확인했다는 표시도), 앱 정보(앱 버전, 운영체제, GPU 이름). 환불 요청에는 서버가 가진 주문과 키 정보를 붙여요: 플랜, 키를 받은 날과 만료일, 받은 경로, 구독 번호, 주문 코드, 입금자명, 주문 상태, 결제 방식, 키를 받은 지 며칠, 적은 키가 다른 구매의 키이면 그 키 식별 번호와 주문 코드. 판매자는 승인이나 거절(거절 사유), 환불 금액, 막은 키를 적어요 | 문의에 답하기, 청약철회와 환불 처리, 그 기록 |
| 구독 관리 (카드 구독 키) | 키 전체(서명 확인에만 쓰고 저장하지 않아요), 구독 번호 | Lemon Squeezy에서 그 구독의 관리 페이지 주소를 받아 열어 주기 |
| 사용 통계 (선택: 사용권 계약 동의 화면의 '사용 통계 보내기'로 골라요. 처음에는 체크되어 있고, 나중에 설정에서 바꿀 수 있어요) | 앱이 만든 무작위 설치 번호, 앱 버전, 운영체제, 플랜, 프레임 생성 배수, 원클릭 게임 부스트 사용 여부, 접속한 국가(Cloudflare가 알려 줘요), 처음과 마지막 연결 시각 | 사용 현황 파악, 서버 부하에 맞춰 보내는 간격 조절 |
| 너무 많은 요청을 막을 때 | IP 주소로 만든 해시값(회원 가입과 로그인, 고객센터 요청), 고객센터의 하루 한도를 셀 때 키 식별 번호나 주문 코드별 요청 수, 판매자 화면에 접속한 IP 주소로 만든 해시값(비밀번호를 틀린 횟수를 셀 때), 구독 관리 링크를 받은 키 식별 번호별 하루 횟수 | 남용과 비밀번호 추측 막기 |
| 판매자 작업과 자동 처리를 기록할 때 | 판매자의 작업(키 발급과 막기, 결제 승인과 거절, 주문 삭제, 환불 승인 · 거절 · 완료, 회원 차단과 삭제, 복구 코드 재발급, 추천 코드 관리, 문의 삭제 등)과 자동 처리(카드 결제 승인과 갱신, 추천 코드 사용, 초대 보상)의 시각과 상세: 주문 코드, 키 식별 번호, 구독 번호, 회원 아이디, 추천 코드, 문의 번호, 환불 금액, 거절 사유 등. 메일 주소는 가린 형태(예: a***@e***.com)로, 키 메모 · 입금자명 · 결제 메모 · 이름표는 첫 글자만 남겨요. 구독 관리 링크를 내줄 때마다 키 식별 번호와 구독 번호를 남겨요 | 판매자가 무엇을 했는지 확인 |
| 판매자가 Cloudflare의 로그 기능을 켠 경우 | 판매자 서버로 온 요청의 주소(주문 코드, 키 식별 번호, 구독 번호, 문의 번호, 판매자 화면의 검색어가 들어갈 수 있어요) 같은 요청 정보와 판매자 서버의 오류 기록(회원 데이터베이스 연결 오류의 동작 이름, 상태, 오류 코드와 메시지) | 서버 문제 진단 |

- 키 전체를 고객센터에 보내면(환불 요청, 구독 관리) 서버는 서명을 확인하는 데만 쓰고 저장하지 않아요. 문의에는 키 식별 번호만 남아요.
- 문의의 확인 코드는 서버에 해시값만 저장해요. 코드를 잃으면 그 문의를 다시 열 수 없어요.
- 사용 통계에는 키, 메일 주소, 게임 이름, 하드웨어 정보를 보내지 않고, IP 주소를 저장하지 않아요.

## 제2조 보유 기간, 파기 절차와 방법

| 정보 | 보유 기간 |
|---|---|
| 주문 | 주문이 마지막으로 바뀐 날부터 90일 |
| 앱이 키를 받아 가기 위한 대기 정보(키 전체) | 카드 결제 7일, 직접 결제 30일. 고객센터의 환불 요청으로 환불을 마치면 그때 지워요 |
| 키 기록(키 전체, 메일 주소, 메모), 메일 주소로 키를 찾는 색인, Lemon Squeezy 주문 번호와 키의 연결, 막은 키 목록 | 보관 기간을 정하지 않았어요 — 판매자가 지울 때까지. 키를 확인하고 막는 데 써요. 막은 키 목록의 한 줄은 판매자가 막기를 풀면 지워요. 판매자 화면에는 나머지를 지우는 기능이 없어서, 지워 달라고 하면 판매자가 Cloudflare 저장소에서 직접 지워요 |
| 구독의 지금 키(구독 번호와 그 구독의 최신 키 전체, 다음 기간의 키를 받아 갈 때 써요) | 구독이 활성 상태가 아니게 되면(해지, 일시정지, 결제 밀림, 만료 등) 또는 그 키를 막으면(환불 등) 지워요 |
| 구독의 키 목록(구독 번호와 그 구독으로 발급한 키의 식별 번호, 최근 200개. 환불할 때 그 구독의 키를 모두 막는 데 써요) | 마지막으로 키를 더한 날부터 400일 |
| 같은 결제 알림을 두 번 처리하지 않기 위한 표시(구독 번호, 결제 번호) | 400일 |
| 구독의 플랜 정보(구독 번호와 플랜) | 보관 기간을 정하지 않았어요 — 판매자가 지울 때까지 |
| 추천 코드와 초대 코드의 기기 번호 | 90일 |
| 추천 코드(이름표 포함) | 보관 기간을 정하지 않았어요 — 판매자가 지울 때까지. 판매자 화면에서 지울 수 있어요 |
| 회원 정보 | 탈퇴하거나 판매자가 회원을 지울 때까지. 오래 쓰지 않아도 자동으로 지우지 않아요. 탈퇴하면 운영 중인 데이터베이스에서 바로 지우고, Supabase의 백업에는 최대 7일 남았다가 지워져요(아래 백업). 다만 회원 아이디는 키 기록의 메모(초대 보상, 보관 기간을 정하지 않았어요 — 판매자가 지울 때까지), 판매자 작업 기록(180일), 문의(그 문의의 보유 기간)에 남아요 |
| 로그인 세션 | 90일. 로그아웃하거나 비밀번호를 바꾸거나 판매자가 회원을 차단하면 바로 지우고, 회원마다 최근 5개만 남겨요. 만료된 세션은 매시간 지워요 |
| 회원 가입과 로그인의 IP 해시값 | 정시부터 1시간 단위로 세고, 그 시간이 끝난 뒤 매시 7분에 도는 정리에서 지워요. 보통 1시간 남짓이고, 정리가 실패하면 더 남을 수 있어요 |
| 고객센터 문의 | 결제와 환불 문의는 3년, 그 밖의 문의는 1년. 문의가 마지막으로 바뀐 날(글, 답장, 상태 변경, 새 답장 읽음)부터 세요 |
| 환불 요청과 키의 연결(카드 환불 알림이 그 요청을 닫게 하는 것) | 요청을 보낸 날부터 3년 |
| 고객센터의 하루 한도 기록(키 식별 번호나 주문 코드별 요청 수) | 2일 |
| 고객센터 요청의 IP 해시값 | 마지막 요청 뒤 1시간까지 (판매자 서버의 저장소, 서버 메모리와 Cloudflare 캐시) |
| 구독 관리 링크를 받은 키 식별 번호별 하루 횟수 | 2일 |
| 구독 관리 페이지 주소 | 30분 (서버 메모리와 Cloudflare 캐시) |
| 새 답장을 읽었다는 표시(문의 번호와 시각) | 1일 (서버 메모리와 Cloudflare 캐시, 고객센터의 하루 한도가 찬 날에만) |
| 판매자 화면의 '새 소식'(문의 번호, 종류, 시각만) | 30일, 최근 1,000줄까지. 문의를 지우면 함께 지워요 |
| 사용 통계의 설치별 기록 | 마지막 연결 뒤 90일. 날짜별 합계(사용자 수 등 숫자만)는 지우지 않아요 |
| 판매자 화면에 접속한 IP 주소의 해시값(비밀번호를 틀린 횟수, 로그인이 이어지는지) | 마지막으로 틀린 뒤 15분, 로그인은 마지막 접속 뒤 30분 |
| 판매자 화면 접속 기록(로그인, 회원 · 구매 정보를 본 시각, 접속한 IP 주소의 해시값, 본 화면과 대상. 검색어는 남기지 않아요) | 1년 |
| 판매자 작업 기록 | 180일 |
| 탈퇴하거나 판매자가 지운 회원 아이디의 해시값(서버만 아는 값을 섞어 만들어요. 다른 사람이 같은 아이디로 다시 가입하지 못하게 해요) | 보관 기간을 정하지 않았어요 — 판매자가 지울 때까지 |
| Cloudflare의 로그(판매자가 켠 경우만) | Cloudflare가 정한 기간 (Cloudflare 안내: 무료 요금제 3일, 유료 요금제 7일) |
| /help가 브라우저에 저장한 문의 목록 | 직접 지울 때까지 (제6조) |

- 개인정보는 전자 파일로만 저장해요. 보유 기간이 지나면 저장소가 그 기록을 자동으로 지워요(Cloudflare 저장소의 만료 삭제, 사용 통계와 회원 데이터베이스의 매시간 정리). 서버 메모리에 있는 사본은 기간이 지난 뒤 다음 정리 때나 서버가 다시 시작할 때 사라져요.
- 백업: 지우거나 기간이 지나 지운 기록도 서비스 회사의 백업과 복구 기능에 잠시 남아요. 사용 통계, 날짜별 합계, 판매자 화면의 '새 소식'처럼 Cloudflare의 데이터베이스(Durable Object)에 두는 기록은 최대 30일, Supabase의 회원 정보는 최대 7일 동안 남았다가 저절로 지워져요. 판매자는 이 사본을 장애 복구에만 쓰고, 백업에서 되살리면 그 전에 지운 기록을 다시 지워요.
- 판매자는 기간 전에도 주문, 문의, 회원, 추천 코드를 판매자 화면에서 지울 수 있어요.
- 보관 기간을 정하지 않은 기록을 지울 때는 판매자가 Cloudflare 저장소에서 그 기록을 직접 지워요.

## 제3조 제3자 제공

판매자는 개인정보를 제3자에게 제공하지 않아요. 법령에 따라 제공해야 하는 경우만 예외예요.

판매자는 디스코드 서버에 공지를 올리지만, 판매자가 쓴 글만 보내고 이용자의 정보는 보내지 않아요.

### 앱이 직접 연결하는 곳

아래는 판매자 서버를 거치지 않고 앱이나 브라우저가 직접 연결해요. 연결하면 상대 회사가 IP 주소와 요청 정보를 받아요.

- GitHub, Inc. (미국): 새 버전 확인과 내려받기. 설정의 '새 버전을 자동으로 확인하고 미리 받아 두기'를 끄면 자동으로 연결하지 않아요.
- macOS에서 Windows 게임 기능을 설정할 때: Wine을 GitHub에서, Steam 설치 파일을 Valve의 배포 서버에서 내려받고, Apple 개발자 페이지를 브라우저로 열어요.
- 계좌이체 · 직접 결제: 판매자가 안내한 결제 페이지를 브라우저로 열어요. 그 페이지에 적는 정보는 그 결제 서비스가 처리해요.

## 제5조 정보주체의 권리와 행사 방법

- 이용자는 언제든지 자신의 개인정보를 보여 달라고(열람), 고쳐 달라고(정정), 지워 달라고(삭제), 처리를 멈춰 달라고(처리정지) 요구할 수 있고, 동의를 철회할 수 있어요. 법정대리인이나 위임을 받은 사람도 할 수 있어요.
- 요구하는 곳: 앱의 '고객센터' → '문의하기'(문의 종류 '기타'), 웹 /help, 또는 제10조의 메일 주소.
- 직접 할 수 있는 것:
  - 회원 탈퇴: 앱의 '◈ 계정' → '회원 탈퇴'. 운영 중인 데이터베이스의 회원 정보가 바로 지워지고, 백업에는 최대 7일 남아요. 다른 기록에 남는 회원 아이디는 제2조에 적었어요.
  - 비밀번호 변경: 앱의 '◈ 계정'.
  - 사용 통계 끄기: 사용권 계약 동의 화면이나 앱의 '설정'에서 '사용 통계 보내기'를 꺼요. 끄면 이 PC의 설치 번호도 지워지고, 서버의 기록은 마지막 연결 뒤 90일이 지나면 지워져요.
  - 문의 닫기, /help의 '목록에서 빼기'.
- 본인 확인: 문의는 문의 번호와 확인 코드, 키 정보는 키 전체, 회원 정보는 로그인으로 확인해요. 이것이 없으면 결제 내역 등으로 확인하고, 판매자가 더 물어볼 수 있어요.
- 판매자는 요구를 받은 날부터 10일 안에 처리하거나 답해요. 법령에 따라 요구를 들어줄 수 없으면 그 이유를 알려요.
- 회원 아이디는 바꿀 수 없어요. 보낸 문의의 글은 고칠 수 없으니 답장으로 바로잡아 주세요.

## 제6조 자동 수집 장치

- 쿠키: 판매자 서버는 쿠키를 만들지 않아요.
- 웹 /help의 브라우저 저장소(localStorage): 문의를 보내거나 열면 그 브라우저에 문의 번호, 확인 코드, 제목, 저장한 시각을 최대 20개까지 저장해요. 같은 브라우저에서 문의를 다시 열 수 있게 하려는 것이고, 문의를 열 때 말고는 서버로 보내지 않아요. 원하지 않으면 '목록에서 빼기'를 누르거나 브라우저 설정에서 이 사이트의 데이터를 지우거나 막으세요. 저장하지 않아도 /help는 쓸 수 있고, 그때는 문의 번호와 확인 코드를 직접 복사해 두세요.
- 앱의 사용 통계: 사용권 계약 동의 화면에서 '사용 통계 보내기'를 켜 둔 경우에만(처음에는 체크되어 있어요), 앱이 켜져 있는 동안 1분에서 1시간 간격(서버가 정해요)으로 제1조의 사용 통계를 보내요. 동의를 마치기 전에는 보내지 않고, 앱의 '설정'에서 끌 수 있어요.
- 앱의 결제 확인: 주문을 기다리는 동안(주문한 뒤 90일까지) 앱이 켜져 있으면, 주문 코드를 보내 키가 나왔는지 판매자 서버에 물어봐요. 주문한 뒤 1시간 동안은 1분마다, 하루까지는 15분마다, 그 뒤에는 1시간마다예요(카드 결제는 처음 10분 동안 10초마다). 키를 받거나 주문이 거절 · 환불 · 삭제되면 멈춰요. 기다리기를 멈춘 주문(앱에서 취소했거나 90일이 지난 주문)은 '★ 플랜' 화면을 열 때 40일까지, 한 주문에 1시간에 한 번까지 다시 물어봐요.
- 앱의 키 확인: 키를 등록한 앱은 켤 때와 켜 둔 동안 20시간에 한 번까지 키 식별 번호를 보내 판매자가 키를 막았는지 물어봐요. 카드 구독 키는 끝나기 7일 전부터 끝난 뒤 45일까지 6시간마다(PC가 절전에서 깨어나거나 인터넷이 다시 연결될 때도) 구독 번호와 지금 키를 보내 다음 기간의 키를 받아 와요. 구독이 끝났다는 답을 받으면 하루에 한 번까지만 물어봐요.
- 앱의 답장 확인: 판매자의 답을 기다리는 문의(마지막으로 바뀐 지 14일 안)가 있으면, 앱이 켜져 있는 동안 30분마다(서버가 바쁘면 최대 2시간마다) 그 문의의 번호와 확인 코드를 보내 답장이 왔는지 물어봐요. 기다리는 문의가 없으면 보내지 않아요.
- 이 확인들은 판매자 서버에 새 기록을 남기지 않아요. 답장 확인에는 제2조의 '고객센터 요청의 IP 해시값'이 쓰여요.
- /help, 이 처리방침 페이지(/privacy), 결제 완료 페이지는 외부 스크립트, 글꼴, 분석 도구를 불러오지 않아요.

## 제7조 이 PC에만 남는 정보

앱은 아래 정보를 이 PC의 SystemBoost 데이터 폴더(%APPDATA%\SystemBoost, 포터블 판은 앱 옆의 data 폴더)에 두고 서버로 보내지 않아요.

- 동의한 사용권 계약의 판과 시각, 언어, 업데이트와 표시 설정, 바꾸기 전 설정의 백업
- 프레임 생성 기록(시각, 게임 이름, 모드, 프레임 수)과 엔진 기록(최근 8개)
- macOS에서 등록한 Windows 게임의 이름과 경로

아래 정보도 이 폴더에 두고, 해당 기능을 쓸 때만 그 일부를 서버로 보내요: 라이선스 키, 기기 번호, 진행 중인 주문(90일 뒤 지워요. 기다리기를 멈춘 주문은 40일), 보낸 문의의 번호, 확인 코드, 제목(최대 20개), 회원 아이디와 로그인 세션, 사용 통계 설정과 설치 번호.

앱을 지워도 이 폴더는 남아요. 지우려면 앱을 끈 뒤 폴더를 직접 지우세요. 회원이라면 먼저 로그아웃하거나 탈퇴하세요.

## 제8조 만 14세 미만 아동

- 회원 가입은 만 14세 이상만 할 수 있어요. 가입할 때 만 14세 이상이라는 확인을 받아요.
- 결제, 고객센터, 사용 통계에서는 나이를 묻지 않아요. 만 14세 미만이라면 법정대리인이 대신 문의해 주세요.

## 제9조 안전성 확보 조치

판매자는 개인정보를 지키려고 다음과 같이 해요.

- 앱은 판매자 서버에 암호화된 연결(HTTPS)로 연결하고, 판매자 서버는 Lemon Squeezy에 HTTPS로 연결해요.
- 비밀번호는 서버만 아는 값과 섞은 뒤 bcrypt로 해시해서 저장하고, 원래 비밀번호는 저장하지 않아요. 복구 코드, 로그인 세션, 문의 확인 코드도 서버에는 해시값만 저장해요.
- IP 해시값은 서버만 아는 값을 섞어 만들어요. 고객센터의 IP 해시값은 마지막 요청 뒤 1시간까지만 둬요. 판매자 서버는 IP 주소를 그대로 저장하지 않아요. 판매자 화면의 비밀번호를 틀린 접속도 IP 해시값으로 세요(마지막으로 틀린 뒤 15분).
- 카드 번호는 받지 않아요. 고객센터로 온 키 전체는 확인에만 쓰고 저장하지 않아요. 문의 확인 코드는 주소(URL)에 넣지 않아요.
- 판매자 화면의 정보는 판매자 비밀번호가 있어야 볼 수 있고, 비밀번호를 여러 번 틀리면 잠겨요(같은 IP에서 5번 틀리면 마지막으로 틀린 뒤 15분, 모두 합쳐 한 시간(정시 기준)에 20번 틀리면 그 시간이 끝날 때까지).
- 회원 데이터베이스는 판매자 서버만 비밀 키로 접근할 수 있게 권한을 막아 두었어요.
- 카드 결제 알림은 Lemon Squeezy의 서명이 맞는 것만 받아요.
- 고객센터와 회원 기능은 요청 횟수를 제한해요(같은 IP의 1시간 한도, 고객센터는 하루 한도도 있어요).
