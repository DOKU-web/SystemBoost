카드 결제 설정 (Lemon Squeezy)
  1. API 키 · 웹훅 서명 비밀
    바탕화면의 'SystemBoost 카드 결제 키 넣기.cmd'를 더블클릭해서 직접 넣어요. 여기에는 저장되지 않고 보이지도 않아요.
  2. 웹훅 — Lemon Squeezy Settings → Webhooks에서 아래 주소를 넣고, 서명 비밀은 위에 넣은 것과 같은 값으로 해요.
    보낼 이벤트: subscription_created, subscription_updated, subscription_payment_success, subscription_payment_refunded, order_refunded
  3. 상점과 상품 번호 — 구독 상품을 플랜마다 하나씩 만들고 번호를 넣어요. 비워 둔 플랜은 카드로 팔지 않아요. 5대·10대 묶음은 카드로 팔지 않고 아래 '결제 링크'로만 팔아요.

테스트 모드에서 만든 상품 번호와 API 키는 실판매에서 쓸 수 없어요. 실판매로 바꿀 때는 실판매 상품 번호와 API 키로 다시 넣으세요. 결제 금액과 수수료는 Lemon Squeezy 상품에서 정해요.

결제 신청 구매자가 앱에서 '결제하기'를 누르면 신청이 생기고, 결제했다고 알리면 '결제 확인 요청'으로 바뀌어요.

코드메모주는 것사용상태

키 직접 발급 선물·리뷰용이나 앱 밖에서 받은 결제

울트라 키는 프로 기능에 프레임 생성 6·8배, 듀얼 GPU, 게임별 자동 최적화, GPU 오버클럭이 더해져요. 산업 키는 울트라 기능에 방송 모드, 업무 모드, 시작 프로그램 정리(Windows)가 더해져요. 월간·연간은 만료 3일 여유를 더해 발급해요. 다음 결제를 받으면 같은 방식으로 새 키를 발급하면 돼요.

키 5개·10개를 고르면 PC마다 쓸 키가 따로 만들어져요. 키 하나가 공유되면 그 키만 차단할 수 있어요. 주문 코드를 넣으면 구매자 앱에 모든 키가 한 번에 떠요.

결제 링크 수동 확인 방식에서 써요. 비워 둔 플랜은 앱에서 '결제 준비 중'으로 잠겨요

묶음 (연간, 키 5개·10개) — 5대 15%, 10대 25% 할인. 할인 티켓은 쓸 수 없어요. 앱에는 사용권 계약 개정이 시행되는 2026년 12월 9일부터 나와요.
