## Article 1 (Subject of this agreement)
This agreement applies between the Seller and the person who installs or uses SystemBoost (the app, engine, updates and documents, the "Program"; that person, the "User"). The User agrees to this agreement on the app's consent screen before using the Program.

## Article 2 (License)
1. The Seller gives the User a non-exclusive license to use the Program on the User's own computer. A User who bought bundle keys may also use it on computers that User manages (such as a company's work computers or family computers).
2. The Program is licensed, not sold. This agreement transfers no rights in the Program or its components to the User.
3. The User may not transfer the license to anyone else.

## Article 3 (Plans and license keys)
1. The Free plan can be used without a key.
2. The Premium, Ultra and Pro plans are opened with a license key issued by the Seller. The features of each plan are as shown on the sales page.
3. With a monthly or yearly key, paid features lock when the stated period ends and the app returns to the Free plan. A key bought by direct payment, such as a bank transfer, is not charged automatically. A key bought as a card subscription is charged the amount shown at purchase automatically every period until the User cancels, and is extended by one period with each payment. The User can cancel at any time through the subscription management link in the payment email; after cancelling, the app returns to the Free plan when the period already paid ends. If a payment does not go through, the key is not extended.
4. A lifetime key has no limit on its period of use. This does not mean it will work on every future operating system and game.
! 5. A key is for the buyer's own use only. It may not be given to others or made public. Bundle keys follow Paragraph 9.
6. If a key is made public or misused, the Seller may block it. A blocked key returns to the Free plan when the app starts online.
7. A key received with a referral code or an invite code can be used only for the period shown. The Seller may end a referral code at any time. A key already received stays usable for its period.
8. Members can create invite codes. Invite rewards are received as Premium keys for the period shown in the app. A member who uses an invite code at sign-up receives the discount ticket shown in the app. A ticket can be used once on a direct payment within the period shown, and cannot be exchanged for cash or given to anyone else. The Seller may cancel rewards obtained by improper means, such as false accounts, and block those accounts.
! 9. Bundle keys are several yearly keys of the same plan bought at once. One key is used on one computer. The buyer may give the people who use the computers the buyer manages (such as employees or family) the key for that computer, and may not sell, give or make keys public to anyone else. The Seller blocks only a key that was made public or misused; the other keys of the same bundle stay usable. Bundle keys are not charged automatically and cannot take a discount ticket.

## Article 4 (Prohibited acts)

! 2. Copy, sell, rent or redistribute the Program or keys
3. Modify or reverse engineer the Program, except where the law or the license of an open source component allows it
4. Use the published code without permission
5. Remove copyright notices from the Program

## Article 5 (Games and anti-cheat)
1. The Program captures the game's picture and shows it in a separate overlay. It does not inject code into game processes and does not change game memory or game files.
! 2. The Seller has not tested the Program in games that use anti-cheat. The Seller does not guarantee that the Program complies with the terms of use or anti-cheat policy of every game.
! 3. The User must check a game's policy before using the Program with it.

## Article 6 (Features that change system settings)
1. Game boost, the work and streaming features (stream mode, work mode, startup programs), overclocking and power limits run only when the User turns them on. The Program backs up the previous values and provides a way to restore them.
! 2. Overclocking can cause game crashes, system freezes and driver errors. It may also affect the graphics card manufacturer's warranty.
Use small values first, after understanding the risks.
! 3. The Seller does not guarantee that automatic recovery always works when a driver or hardware error has occurred.

## Article 7 (Performance)
1. Frame generation does not increase the frames the game actually draws. It inserts images between frames.
! 2. Turning on frame generation increases input delay. It is not recommended for competitive games.
3. Output FPS follows the monitor's refresh rate unless the User chooses an output rate. A chosen rate can exceed the refresh rate, but a monitor displays only up to its own refresh rate.
4. Measurements on the sales page are results in the stated environment. Actual results differ by PC, game and settings.

## Article 8 (Network use and personal information)
1. The Program sends the key's identifying number to the Seller's license server to check the key, and connects to GitHub to check for updates. Setting up the Windows game environment on macOS downloads the files it needs.
2. While it is on, the Program sends the Seller's server a randomly created install number, the app version, operating system, plan, frame generation multiplier, and whether one-click game boost is in use, for usage statistics. The server also records the country of the connection. Keys, email addresses, game names and hardware information are not sent, and the Seller does not store IP addresses. The install number is deleted 90 days after the last connection.
3. The User can turn off usage statistics in the app's settings.
4. When the User enters a referral code, the Program sends the code and a randomly created device number to the Seller's server. The device number is used only to stop the same device from using a code again, and is deleted after 90 days.
5. Signing up as a member is optional and open only to people aged 14 or over. For members, the Seller keeps the ID, the encrypted password and recovery code, the times of sign-up and last login, the time of consent, and the invite code and invitation records in Supabase's database service. This information is used only to manage members and invite benefits, and is deleted at once when a member leaves.
6. To prevent abuse of sign-up and login, the Seller's server keeps a one-way value made from the connecting IP address for up to 1 hour.
7. How personal information is handled is shown on the sales page.

## Article 9 (Purchase and withdrawal)
1. The User may withdraw from the purchase within 7 days of receiving the key.
! 2. Once the User registers a key and starts using paid features, the digital content is treated as provided and withdrawal may be limited.
The Seller offers a 3-day trial key that can be used before purchase.
3. If the Program differs from what was displayed or advertised, or is provided differently from the contract, the User may withdraw within 3 months of receiving it, or within 30 days of the day the User learned or could have learned of this.
4. When a refund is complete, the Seller blocks the key.
5. Questions about withdrawal and refunds go to the contact shown on the sales page.

2. The Seller compensates for damage caused by the Seller's intent or gross negligence.
! 3. For damage caused by the Seller's minor negligence, compensation covers ordinary damage, up to the amount the User paid for the Program.
4. The Seller is not liable for compatibility problems caused by changes outside the Seller's control, such as operating system, driver and game updates, except where the Seller acted with intent or gross negligence.
